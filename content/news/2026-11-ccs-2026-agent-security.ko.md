---

지난주 헤이그에서 열린 ACM SIGSAC의 CCS 2026에서는 에이전틱 AI의 보안에 대한 관심이 높아지고 있는 것을 확인할 수 있었습니다. 사실 에이전틱 AI라는 개념 자체가 제시된 지 그리 오래되지 않았음에도, 최근 에이전틱 AI를 이용한 다양한 해킹과 보안 사고 사례가 나오면서 많은 관심을 받고 있는 것 같은데요, 특히 올해 발표된 논문 중에는 에이전틱 AI의 도구 호출과 관련된 논문들도 있었습니다.

간단하게 통계만 보자면, 2025년과 2026년 사이의 변화는 다음과 같습니다.

| 항목 | CCS 2025 | CCS 2026 |
|---|---:|---:|
| 본학회 논문 | 316편 | 479편 |
| AI 중심 논문 | 86편 (27.2%) | 124편 (25.9%) |
| 그중 LLM 중심 | 36편 (11.4%) | 72편 (15.0%) |
| 그중 LLM 외 ML(적대적 예제, 연합학습 등) | 50편 (15.8%) | 52편 (10.9%) |
| AI 에이전트 보안(에이전트가 대상) | 1편 | 13편 |
| 에이전트를 공격/분석 도구로 쓴 논문 | 0편 | 3편 |
| MCP 언급 논문 | 0편 | 2편 |
| ML 트랙 세션 | 10개 (전체 60개) | 14개 (전체 74개) |

제가 모든 세션에 들어갈 수도 없었고, 모든 초록을 다 읽기에도 편수가 너무 많았기에... OpenAlex로 학회 본 세션에 발표된 논문의 제목과 초록을 모아 확인한 결과입니다. 두 해에 같은 키워드 기준을 적용했고, 에이전트 논문은 키워드로 추린 후보를 직접 확인했습니다. 포스터, 데모, 워크샵은 뺐습니다. 자체 집계라 기준에 따라 수치는 조금씩 달라질 수 있습니다.

에이전트를 대상으로 한 보안 논문은 2025년 1편에서 올해 13편으로 늘었고, 에이전트를 공격이나 분석 도구로 쓴 논문도 0편에서 3편이 되었습니다. 에이전틱 AI라는 개념이 나온 지 얼마 되지 않았으니 전년 대비 증가는 당연하다고 하더라도, 관련 보안 이슈가 뉴스로 다뤄진 지 길어야 1년이 안 되었음을 감안하면 비중이 빠르게 높아지고 있는데요, 에이전트 관련 논문 16편은 본학회 논문의 3.3%로, 지난해 0.3%에서 크게 늘었습니다. LLM 같은 모델 자체의 보안 연구에서 AI 에이전트 자체의 보안 기술로 연구 분야가 빠르게 넓어지고 있는 것 같습니다.

에이전트와 외부 도구를 잇는 표준 인터페이스로 자리 잡아 가는 MCP(Model Context Protocol)를 다룬 논문은 아래 두 편입니다.

- [ContractGuard: Auditing Semantic Contracts of MCP Tools for Security Violations](https://dl.acm.org/doi/10.1145/3830454.3846789): MCP 도구의 설명과 실제 구현이 어긋나는 지점을 정적 분석과 LLM 추론으로 찾아내는 감사 기법, 실제 MCP 서버 1,000개의 도구 3,586개에서 보안 문제 116건 발견
- [Governing AI Agent with Capability and Delegation Chain](https://dl.acm.org/doi/10.1145/3830454.3846604): API와 파라미터 범위를 제한한 암호학적 자격증명과 위임 사슬로, 에이전트가 여러 단계에 걸쳐 권한을 넘길 때도 최소 권한을 지키게 하는 프레임워크(CapAgent), MCP 연동 포함

저희 연구센터는 인공지능 에이전트 운영에 필요한 안전한 에이전트 도구 연동 기술을 연구하고 있습니다. 도구로 제공할 수 있는 정보 자산을 어떻게 관리할지(국가망 보안체계 N2SF 등), MCP 도구의 안전성을 어떻게 확인할지, 위변조 공격을 어떻게 판단할지 등을 연구 중입니다. 많은 관심 부탁드립니다.
