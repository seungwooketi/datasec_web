# 검색엔진 소유확인 파일

여기 둔 파일은 빌드가 `docs/` **루트**로 복사한다 — 즉 `https://www.datasec.work/<파일명>` 이 된다.

⛔ **`docs/` 에 직접 두지 마라.** `build.py` 가 매 빌드마다 `docs/` 를 통째로 지우고 다시 만든다.
직접 둔 파일은 다음 빌드에서 **에러 없이 사라지고**, 소유확인이 조용히 끊긴다.

## 넣게 될 것

| 어디 | 파일 | 비고 |
|---|---|---|
| 네이버 서치어드바이저 | `naverXXXXXXXX.html` | ⚠️ 소유확인에 **만료가 있다**(1년, 30일 전 알림 메일). 지우면 안 된다 |
| Bing Webmaster Tools | `BingSiteAuth.xml` | Search Console 에서 가져오면 불필요 |
| IndexNow | `<key>.txt` | 나중에 |

⭐ **구글은 여기 쓰지 않는다.** DNS TXT 방식이 낫다 — Cloudflare 에 레코드 하나면 되고,
빌드가 `docs/` 를 다시 만드는 것과 무관하며, apex·www·서브도메인을 한 번에 덮는다.

⚠️ 네이버는 **메타태그 방식을 쓰지 말 것.** 소유확인 메타태그 검증에서 JS·meta refresh 리다이렉션을
지원하지 않는데, 지금 루트(`/`)가 그 형태다. 파일 방식이 확실하다.
