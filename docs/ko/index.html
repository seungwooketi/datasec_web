SECURITY

인공지능 안전

AI Safety

AI 모델과 데이터를 지키고, 납품되는 AI를 믿을 수 있게 검증하는 기술

엣지 로봇 AI의 추론을 하드웨어로 격리된 공간에서 기밀로 수행하고, 모델에 담긴 제조 노하우를 비가역 학습과 워터마킹으로 보호합니다. AI의 구성을 기록한 AI-BOM으로 납품되는 AI의 취약점과 정합성을 검증하는 기술도 개발합니다.

대표 과제제조 핵심기술 보호를 위한 AI 로봇/휴머노이드의 지능보호 및 보안 실행 기술 개발산업부 / 주관 / 2026-08 ~ 2029-12
SECURITY

물리보안

Physical Security

영상과 센서로 현장의 보안 위험을 알아채고 대응하는 기술

영상, 소리, 센서 데이터를 함께 분석해 건물과 산업 현장의 보안과 위험 상황을 알아채고 대응합니다. 서버와 경량 엣지 단말에서 동작하는 보안 AI, 카메라 단말이 스스로를 보호하는 개방형 영상보안 플랫폼을 연구합니다.

대표 과제멀티모달 데이터 통합 분석 기반 지능형 보안·위험대응 시스템 개발과기정통부 / 주관 / 2024-06 ~ 2027-12
DATA

멀티모달 데이터

Multimodal Data

형태와 출처가 서로 다른 데이터를 함께 이해하고 연결하는 기술

영상, 소리, 센서, 텍스트를 함께 분석하는 AI를 연구하고, 멀티모달 데이터로 답을 보강하는 검색 증강 생성의 품질을 검증합니다. 흩어진 이기종 데이터를 융합하고 네트워크가 불안정한 환경에서도 변환해 공유하는 기술도 개발합니다.

DATA

콘텐츠

Content

AI로 디지털 휴먼과 소리, 공간을 만들고 감각을 전하는 실감 콘텐츠 기술

사람의 외형과 움직임을 생성하는 모델, 장면에 맞는 효과음과 배경음을 자동으로 만드는 기술을 개발합니다. 시야가 가려진 공간을 3D로 재구성하고, 기종이 다른 XR 기기에서 청각과 촉각을 사용자에게 맞추는 기술도 연구합니다.

대표 과제저가시-비가시 환경에 대한 3D 공간 구성과 시각화 기술 개발과기정통부 / 주관 / 2026-04 ~ 2028-12
