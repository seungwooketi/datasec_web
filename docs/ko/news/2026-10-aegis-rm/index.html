로봇 지능을 지키는 AEGIS-RM 과제 협약 완료

생성형 AI가 로봇 안으로 들어오면서 AI가 글 대신 행동을 출력하는 시대가 되고 있는데요, 다만 이렇게 행동을 내는 물리 AI를 지키는 보안은 아직 준비가 덜 된 것 같아요. 산업통상부와 한국산업기술기획평가원(KEIT)이 지원하는 2026년도 로봇산업기술개발사업에서 「제조 핵심기술 보호를 위한 AI 로봇/휴머노이드의 지능보호 및 보안 실행 기술 개발」(AEGIS-RM) 과제의 협약을 마쳤습니다. 2026년 8월부터 2029년 12월까지 4년 과제이며, 한국전자기술연구원이 주관합니다.

AEGIS-RM은 Action-aware Edge-Guarded Intelligence and Secure-execution for Robots and Manufacturing의 줄임말입니다. 학습, 추론, 제어 전 주기에 걸쳐 로봇 지능과 그 안에 담긴 제조 지식을 지키는 것이 목표입니다.

왜 로봇 지능을 지켜야 할까요

제조 현장의 로봇에는 작업 궤적, 그립 자세(grasp pose), 정렬 기준, 프레스 공정 파라미터 같은 숙련자의 노하우가 학습되어 들어갑니다. 모델이 탈취되거나 역추론되면 공정 노하우가 그대로 밖으로 나갈 수 있구요. 텍스트를 내는 LLM과 달리 VLA나 로봇 파운데이션 모델(RFM)의 잘못된 출력은 곧바로 모터 동작이 되어 불량이나 안전사고로 이어질 수 있습니다.

그래서 기존 IT 보안(DLP, 프롬프트 필터)이나 기능안전(ISO 10218, ISO 13849)을 그대로 옮겨 쓰기는 어려워 보입니다. 악의적인 프롬프트만으로 로봇을 위험한 동작으로 유도할 수 있음을 보인 RoboPAIR 연구도 실행 시점의 방어가 필요하다는 점을 보여 주는 듯 합니다.

4단계 방어 체계

엣지에서 동작하는 로봇 지능(RFM)을 가운데 두고 네 겹으로 감싸는 구조입니다. 안쪽 두 겹은 보호, 바깥 두 겹은 방어를 맡습니다.

  1. TEE 기반 신뢰 실행 환경: 모델을 하드웨어 격리 영역에서 기밀 추론하고, 컨테이너 인증으로 종적 이동을 막습니다
  2. 내재화 지식 보호: 학습데이터 오염과 백도어를 막고, 비가역 학습과 워터마킹으로 모델 속 노하우를 지킵니다
  3. 지능-제어 분리와 이상 탐지: 직접, 간접, 시각 프롬프트 인젝션과 제어 파라미터 위변조, 행동 기반 이상동작을 탐지합니다
  4. 제로트러스트 정책과 통합관제: ZTA 관제와 비상정지, 사내 지식(KB/ERP) 유출 방지를 맡습니다

주요 대상 기술

여섯 개 보안 모듈(M1~M6)로 나누어 개발합니다.

  • HW 신뢰 실행 환경(M1): ARM TrustZone/OP-TEE 기반 TEE 런타임, Secure Boot와 원격 증명, Confidential Containers
  • 지능-제어 분리 프레임워크(M2): 판단과 제어 영역을 나누고 실시간 의미, 물리 안전 게이트로 명령을 검증, 다층 프롬프트 주입 방어
  • 행위 기반 이상탐지(M3): 통계와 역동역학 모델, 딥러닝을 결합한 물리잔차 하이브리드 탐지, 사이버 유발 이상과 기계 결함의 구분, XAI 탐지 근거
  • AI 모델 보호(M4): 모델 추출 탐지, 행동공간 워터마킹, TEE 기반 안전 추론
  • 보안 학습 파이프라인(M5): 특징 수준 추상화로 작업 성능을 지키는 비가역 학습, RFM 학습 파이프라인과 KB/ERP 커넥터 보안
  • 통합 보안 관제와 자율 대응(M6): SIEM 상관분석, ZTA(OPA) 정책 엔진, XAI 대시보드, 사람 승인(HITL)을 결합한 자율 보안 대응(SOA)

모델 역추론 성공률 30% 이하, 비정상 접근 탐지와 차단율 90% 이상을 목표로 하고, 보안을 적용해도 공정 품질과 작업 성능이 유지되는지 함께 검증할 계획입니다.

컨소시엄

보안과 로봇, 두 축으로 구성했습니다.

  • 한국전자기술연구원(주관): 인공지능데이터·보안연구센터가 이상탐지, 보안 학습, 관제와 자율 대응을, 지능로보틱스연구센터가 지능-제어 분리와 플랫폼 정합을 맡습니다
  • 서울대학교: HW-TEE, TEE 추론, Confidential Containers, 비가역 학습
  • (주)엔키화이트햇: 레드팀과 침투테스트, 모델 보호 검증, 보안 관제
  • 로보웍스(주): 로봇 플랫폼과 테스트베드, 커넥터 보안
  • (주)경우정밀: 수요기업. 브레이크 드럼 프레스 공정과 데이터 제공, 현장 실증

실증은 경우정밀의 실제 프레스 공정에서 원통형 부품을 집어 정렬하고 양손 버튼으로 프레스를 기동하는 작업부터 시작해, 검수, 적재, 이동 플랫폼으로 넓혀 갈 예정입니다.
